# PoultryLens AI

Streamlit research prototype for chicken image classification (Cocci, Healthy, Salmo).

## Run locally
Keep `app.py`, `requirements.txt`, and `Hybrid_Model.keras` in the same folder.
Install: `python -m pip install -r requirements.txt`
Run: `python -m streamlit run app.py`

## Important
Confirm the saved model's output-class order and preprocessing against the training notebook. Recorded metrics and dataset counts should be verified against final evaluation artifacts before public release. This is a research prototype, not a veterinary diagnostic tool.
